# Portfolio — Vo Nguyen Phu Qui

Next.js (App Router) portfolio site, deployable on [Vercel](https://vercel.com).

## Setup

```bash
npm install
npm run dev
```

## Demo videos

Project demo videos are configured in `config/media.ts`. Add Supabase (or other) URLs when available; until then the UI shows poster images.

## Build

```bash
npm run build
npm start
```
